# SRC OS Assets v1

Working asset kit for the Second Source visual system.

## Included

- Second Source logo without the domain name
- SRC square icon
- DRIP wallpaper used by SRC OS
- Microgramma and Eurostile font files used by the site
- Source 1 / Dusk and Source 2 / Night still scenes in editable SVG and 1600 × 1000 PNG
- Crosshair and interface icons
- Editable SRC OS window frame in SVG and 1200 × 720 PNG
- CSS color and dimension tokens

The SVG icons use `currentColor`, so they can be recolored in CSS or in a vector editor. The window frame and scene files are standalone SVGs and can be opened directly in Figma, Illustrator, Affinity Designer or a browser.
